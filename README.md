# Money Save

Save • Secure • Grow

## Live app
GitHub Pages deployment for the Money Save web app.

## Product foundation
Money Save is a personal finance platform focused on saving, protecting money and understanding future growth.

## Current app
- Mobile-first dashboard
- Income, expense and savings overview
- AI Financial Friend prototype
- Expense tracker
- AI Savings Challenge
- Coin/reward milestones
- Reward verification workflow
- Live Meeting Gateway
- Free/Premium usage presentation
- Profile and Owner Admin Command Center

## Approved rules
- Free users: 30 AI questions/day
- Premium users: 100 AI questions/day
- Free live viewing: 10 minutes/day
- Premium live viewing: 30 minutes/day
- 30,000 coins: ₹10 reward eligibility
- 50,000 coins: ₹30 reward eligibility
- Above 50,000: no additional cash tier
- Rewards require verification and are not guaranteed
- Public community must not expose exact savings, income or bank balances
- Investment/business research must be educational and must not guarantee returns or income

## Production roadmap
1. Authentication and unique User ID
2. Supabase/Postgres data layer with row-level security
3. Server-side Owner/Verification/Support roles
4. Server-side AI provider and usage quotas
5. Receipt OCR and secure private document storage
6. PhonePe payment submission and human verification workflow
7. Coin ledger and anti-abuse controls
8. Reward claim, bank verification and payment status
9. Live video provider, AI moderation and appeals
10. Notifications, audit logs and production security
